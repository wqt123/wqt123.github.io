# `wqt123.github.io`

一个基于 `Hugo + GitHub Pages + GitHub Actions` 的免费个人博客。

## 特点

- 免费托管在 GitHub Pages
- 内容优先，直接写 Markdown
- 简约明朗的自定义样式
- 支持文章、标签、专题
- 支持 Mermaid 图

## 本地结构

- `content/posts/`：日更文章
- `content/about/`：关于页
- `layouts/`：自定义模板
- `static/css/`：样式
- `static/js/`：前端脚本
- `.github/workflows/`：自动部署

## 让博客上线

1. 在 GitHub 创建一个空仓库：`wqt123.github.io`
2. 把本地仓库推上去
3. 在 GitHub Pages 中选择 `GitHub Actions` 作为部署源
4. 推送到 `main` 后自动发布
